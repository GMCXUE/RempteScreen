# 双端界面统一优化

范围：主桌面客户端 `apps/desktop-rs/` 与 Flutter 移动客户端 `apps/flutter_client/`。首次实现时只修改源码；用户随后授权三端覆盖安装，记录见下文。此次不涉及服务端变更。

## 界面变化

- 统一蓝色主色、灰色文字层级、成功与失败颜色，以及卡片、输入框、弹窗的圆角和间距。
- 文件传输采用分组任务列表，显示文件类型图标、易读的文件大小、传输进度、完成或失败状态。接收完成后保留“打开所在目录”。完成任务归入记录，减少重复的进度卡片。
- 个人资料采用头像摘要与分组信息；桌面先查看资料，再进入编辑。移动端“我的”和桌面设置均提供资料、消息提醒与投屏画质入口。
- 消息提醒弹窗将系统状态、权限入口和通知测试收进折叠区。Android 保留后台电池、自启动、来电弹出等平台专用入口；桌面保留系统通知设置。
- 通话统一为圆形图标控制、短文字、绿色接通与红色挂断。收起后显示浅色的通话入口。桌面浮层根据聊天输入区的实际高度调整位置，图片草稿增加输入区高度时仍可输入和发送。
- 聊天工具栏、复制与撤回菜单、图片边距、图片查看器和时间文字统一样式。移动端资料更新提示缩短为 1.2 秒。
- 保留已有导航、聊天图片草稿、复制和撤回规则，视频悬浮窗未增加关闭按钮。

## 验证

- 桌面 JavaScript 语法检查。
- 桌面资料与头像保存、失败重试、聊天图片/复制/撤回、连接输入和响应式布局回归。
- 移动端现有 26 项回归：个人资料、头像、聊天、好友未读、通话收起、首页和观看页。
- 使用本地模拟数据生成真实界面截图，检查桌面最小窗口 820×560、移动端窄屏 320×680 和 1.4 倍字体。
- Flutter 静态分析保留已有 `main.dart` 使用音频库实验性 API 的警告；本次界面修改无新增分析问题。

未进行真实设备之间的通话、传输或系统通知测试。
