# 消息页面隐藏重复顶栏

用户要求进入消息页面后隐藏内容区顶部包含“消息”快捷入口的整栏。桌面页面切换已有 messages-workspace 标记，本次通过该状态隐藏 workspace-header，移除占位高度，使会话列表和聊天区直接贴到窗口内容区上边缘。其他页面的标题和消息入口正常恢复，通知跳转仍使用原有页面切换流程。

Flutter 移动端不具有桌面的 workspace-header 或右上角消息快捷入口，无对应重复栏需隐藏；沿用用户明确要求保留的安卓四标签布局，不再同步桌面导航位置。

使用真实桌面 HTML/CSS/JS 和模拟账号检查：消息页整栏隐藏、没有空白占位，设置入口仍可切换页面，切出消息页恢复顶栏，窄窗口未出现横向溢出。预览在 `docs/design/messages-no-topbar-desktop.png`。代码已修改，本次未打包、安装或发布。

## 样式热更新可行性

当前桌面 Tauri 配置的 frontendDist 是本地 `../ui` 目录，页面由构建过程嵌入应用；运行中的已安装版本不会读取源码目录。[Tauri 配置说明](https://v2.tauri.app/reference/config/#frontenddist)明确描述本地目录资源嵌入应用的行为。项目现有更新流程替换完整应用包，不是独立的界面资源更新。

桌面的 HTML/CSS/JavaScript 可以另行实现资源更新机制：签名验证与摘要校验、版本及原生接口兼容检查、下载到应用自己的数据目录、原子切换及失败回滚。接入机制首先需要安装一次包含资源加载器的客户端，之后纯界面改动可只发布资源包并在重载后生效；Rust、采集辅助程序和系统权限相关改动仍需应用更新。此处为方案说明，此说明编写时尚未实现资源热更新。

Flutter 移动端与网页资源不共用这套加载机制；需要独立的 Flutter 代码更新机制，或对预先支持的样式/布局开关使用远程配置。本次没有接入热更新框架或改变现有更新检查行为。
