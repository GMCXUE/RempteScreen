# 消息与好友页面样式统一

双端将最近会话与好友列表拆为“消息”“好友”两个视图，申请只在好友视图集中处理，消息视图显示轻量提醒。已发送申请和黑名单默认折叠，账号 ID 从主界面收起（移动端仍可在我的页面复制，桌面在我的账号展开）。统一头像底框、字号、行距和空白状态。

桌面聊天改为单个圆角分栏容器，管理操作收进更多菜单，聊天背景、气泡与输入区使用既有浅色体系。移动端沿用设备页的白色卡片、蓝色小面积强调和紧凑列表，聊天时间显示减弱视觉权重。好友接口和权限规则不变。

本轮仅修改客户端源码，不部署或覆盖安装。静态检查；尚未真机确认样式。

用户随后要求安装，Mac 测试签名与 Android arm64 release 构建通过，均已覆盖安装并启动，应用数据保留。无需服务端更新。
