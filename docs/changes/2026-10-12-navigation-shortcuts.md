# 2026-10-12 导航入口整理

桌面端左侧保留账号菜单及投送本机、观看设备、文件传输、我的设备四个入口；统一左对齐，缩短侧栏宽度与导航留白。消息从左侧移到内容区右上角，保留未读角标及选中状态。设置从导航列表移到侧栏底部右侧，仅显示齿轮图标，带“设置”提示与无障碍名称；服务器连接状态留在底部左侧。

内容标题统一放入顶栏，随页面切换；消息工作区继续独立管理列表与聊天滚动高度，通知点击仍通过原有消息目标进入对应会话。

移动端最初同步了上述入口调整，但用户明确要求仅保留桌面布局、回退安卓导航。当前移动端恢复“首页、消息、投屏、我的”四个底部标签，未读角标恢复到“消息”，顶栏仅保留原刷新操作；个人资料及设置继续位于“我的”。内部四个页面索引不变，通知定位、聊天页面状态和投屏路由沿用原流程。这是用户指定的平台布局差异。
