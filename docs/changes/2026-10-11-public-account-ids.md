# 固定六位数字账号 ID

用户批准采用六位随机数字账号 ID，用于展示、复制、登录和添加好友。数字范围 100000–999999，不带前导零；永久保存，数据库唯一约束防止重复。内部 users.id 和好友/聊天/设备外键不变。

服务启动时执行 account_schema.mjs 的幂等事务迁移：新增 users.account_id、唯一索引和格式约束，给旧账号逐个分配号码，再设置默认分号函数与非空约束。分号函数通过事务级 advisory lock 串行检查并分配，最多尝试 200 次，失败回滚，不返回重复号码。适合目前的小规模使用；号码接近耗尽时需要扩大位数或改用号码池。新注册通过数据库默认值分号，不改变已有注册和数据导入代码。

公开用户、social/state 和好友搜索增加 accountId 字段，id 继续作为内部协议键。登录接口兼容旧 email 请求字段（其值可以是邮箱或数字 ID），也接受 login 字段。数字 ID 与邮箱共享同一账号登录错误次数限制。搜索兼容旧内部 ID 输入，但双端界面只展示数字 ID。

桌面登录输入支持账号 ID 或邮箱；消息页账号区域可复制数字 ID，好友列表及添加确认显示数字 ID。移动端同步更新登录、个人页复制、好友列表及添加确认。旧服务器未返回 accountId 时显示“待分配”，不把内部 ID 暴露为公开账号号码。

验证：隔离临时 PostgreSQL 中检查真实旧表补号与原密码保留、24 个并发注册号码唯一、格式/唯一约束、邮箱及数字登录、共享登录错误次数限制、搜索/好友关联以及重启后号码和关系保持。原好友私聊 86 项检查通过。桌面 JS 语法检查通过；Flutter 静态检查保留已有 experimental_member_use 警告。
