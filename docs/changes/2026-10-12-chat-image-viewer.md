# 图片查看器

桌面聊天和聊天记录的图片都改用独立 `chat-image` 原生窗口，默认980×760、可调整大小、最小520×380，使用浅色标题栏、浅灰画布和54px图标工具栏，不再显示旧暗色大卡片、标题和文字关闭按钮。支持适应窗口、缩放、原始大小、90度旋转、拖动、滚轮缩放、双击切换原始大小与适应窗口、复制图片。Escape关闭，0适应窗口，+/-缩放，Ctrl/Cmd+C复制。只提供已实现的操作，不显示参考图里尚未实现的编辑、OCR等按钮。

原图和复制通过新窗口专用Rust命令读取，窗口上下文绑定当前登录令牌、好友和消息；服务器继续校验好友关系、清空水位和撤回状态。读取结束再次核对上下文，切图时的迟到结果由JS代次检查丢弃。复制重新请求原图，不复制缓存缩略图。账号退出销毁窗口；聊天轮询收到对应图片撤回时关闭窗口，图片窗口遮住聊天窗口时仍保持该会话同步。新窗口只添加本地窗口权限，不改变服务器协议或数据。

移动端保留原有全屏深色画布和双指缩放，改为紧凑图标工具栏，加入适应窗口、缩放、原始大小、旋转和复制。聊天与历史记录共用查看器，历史中的复制也重新读取原图；异步加载退出后不修改已销毁页面。窄屏320px工具栏不溢出。桌面采用浅色独立窗口、移动端采用深色全屏，这是各平台看图场景的布局差异。

验证：Rust cargo check --locked通过（仓库原有6项警告）；桌面实际HTML浏览器验证缩放、拖动、旋转、原始大小/适应窗口、窗口尺寸变化、复制/失败提示、加载失败重试、切图迟到响应、Escape关闭；聊天回归包含原图复制和主窗口隐藏时的撤回关闭，历史查找回归通过。移动聊天及大图片回归13项通过，新查看器缩放/旋转/复制/重试/退出/窄屏2项通过；静态检查无问题。
