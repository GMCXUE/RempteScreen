# 文件传输记录与 50 MB 上限

按最终确认的范围，服务器仅长期保存传输元数据，不保存文件内容，不提供文件重新下载，不设置 15 天过期。记录包含事件发生时的双方账号 ID/名称、双方设备 ID/名称、文件名、大小、开始与确认时间、结果。旧客户端历史没有这些记录，无法补录。原文件仍通过原有数据通道传输；没有宣称所有流量都绕过媒体转发服务器。

新增 file_transfers 表及 POST/GET/PATCH /v1/file-transfers 接口，数据列不含内容、哈希或本地路径。只有发件人与收件人能列出自己的记录；只有发送方可确认结果。文件连接令牌增加与双方账号及目标设备绑定的签名能力，密码直连和请求同意两条路径保持一致。验证发送设备归属，拒绝伪造/过期令牌，记录创建幂等，结果不可反复改写。分页每页 50 条，按数字主键排序。

开始传输前建立记录，创建失败时不静默发送无记录文件。完成以原有接收落盘回执为依据；结果同步失败不把实际接收成功的文件改报失败，超出十分钟未确认的历史显示“未确认完成”。客户端异常退出同样保留未确认记录。账号或设备后续改名不改写历史名称快照。

电脑与手机均新增历史列表，展示双方、设备、文件名、大小、时间与结果，支持刷新、分页、失败重试；仅当前运行的本地接收记录保留打开目录入口。历史不提供下载按钮。

单文件上限 50 × 1024 × 1024 字节；允许恰好 50 MB 和空文件。桌面与移动发送端、接收端、服务器元数据接口均校验上限。Android 选择文件时先校验声明大小，并在缓存复制时独立计数，未知或错误声明不会绕过上限。发送时文件增长也会被中止，接收侧不允许超出声明大小。

验证：服务器 73 项授权/大小/分页/幂等/快照/重启持久化断言；Rust 大小边界；Android 原生真实流复制边界；Flutter 手机尺寸历史页和目录打开回归；桌面历史页分页与错误恢复；既有连接审批及文件协议回归。生产仅新增记录表与索引，不清理旧数据。

整包目标：macOS 0.2.12、Android 0.2.18，buildCode 2026101307；不发布热更新。
