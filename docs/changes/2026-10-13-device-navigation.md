# 我的设备返回导航修复

移动端“我的设备”是首页内的状态视图，原来只实现了标题栏返回按钮，未消费系统返回事件，因此 Android 返回键或手势可能直接退出应用。现在使用 PopScope 在设备页消费返回并恢复首页；弹窗和其他独立路由仍先由 Navigator 返回，首页保持原有退出行为。

主桌面客户端同时新增“返回上一页面”入口，记住进入设备列表前的页面；重复点击设备入口不覆盖来源。返回通过原侧栏导航执行，保留已有消息刷新逻辑、输入草稿和会话。桌面没有手机系统返回键，采用页面按钮作为平台对应入口。

Mac 验证：真实 HomeScreen 的系统返回、弹窗优先、标题栏返回和首页退出回归，以及已有首页布局/输入回归，共 3 项 Flutter 测试通过；修改文件静态分析无问题。隔离浏览器中的桌面多来源返回、重复进入、观看输入和会话保留检查通过。没有替换手机上正在运行的应用；完整安装包版本与发布验证另行记录。
