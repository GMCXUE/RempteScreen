# 聊天输入区调整

移动端按用户截图要求：输入框有文字时隐藏加号，右侧仅保留发送；清空文字后恢复加号。仅空白字符也显示发送但不可发送，避免隐藏按钮后留下空入口。图片草稿没有文字时仍可通过加号继续添加图片。输入文字时关闭已展开面板；普通文字粘贴及发送后清空逻辑保持原有行为。

桌面端按另一张截图要求缩小输入区：默认一行42px，输入多行时自动增高，上限108px（四行），更多内容在框内滚动。清空、发送完成、切换会话会恢复默认高度，窗口/侧栏宽度变化时重新测量换行。减小输入区外边距并对齐图片与发送按钮，图片预览和失败重试提示仍在输入框内部。移动端此前已采用一到四行输入，保留该行为；桌面图片入口沿用现有布局，不照搬移动端的加号面板，这是用户分平台指定的交互。

验证：移动聊天原有11项回归通过并更新发送/加号切换场景，静态分析无问题；桌面浏览器回归通过，包括空输入高度、多行增高、超过上限滚动、清空恢复、图片发送/复制/撤回/重试和账号切换。实际页面截图 `docs/design/chat-composer-compact-desktop.png` 已检查。当前为源码改动，未发布新更新或覆盖安装。
