# 两端交互动效与聊天渲染优化

桌面原生客户端和 Flutter 移动客户端统一交互节奏：按钮反馈约 120 毫秒，内容切换约 200 毫秒，弹层约 240 毫秒。页面、弹窗、抽屉、提示和聊天附件面板采用有限时长的缓出动画；快速重复操作可以中断，隐藏内容立即停止接收点击、焦点和辅助功能访问。系统减少动态效果设置生效时直接显示最终状态，运行中的动效及时停止。

移动端保留 Android 预测返回与 iOS 边缘返回手势，页面内容切换只保留一份真实子树。首页、消息、投屏、个人页及“我的设备”保留页面状态和滚动位置，非当前页禁用焦点与动画计时器。附件面板平滑展开与收起，系统返回仍先关闭面板或设备子页。

聊天按稳定的消息身份复用行，发送占位消息与服务端确认共用 clientId。仅对正在查看会话时的新消息播放短暂入场，首屏历史、历史分页、轮询、重试和确认不重播；大量补齐时限制同时入场数量。移动端入场只改变绘制位置与透明度，不改变行高及滚动锚点。缩略图按消息和来源缓存解码结果，消息变化或撤回时立即失效；输入文字只重建输入区域，联系人状态无可见变化时不重建列表。

通话和投屏只对控制条执行显隐动效，视频节点不参与淡入、缩放或尺寸补间；隐藏控制条时预览小窗位置固定。桌面使用现有媒体节点，移动端保留现有视频 GlobalKey 和会话生命周期，不因动效重建连接。

平台差异：桌面使用 CSS 和 Web Animations 实现短暂过渡，原生弹窗关闭和隐藏仍由既有界面状态立即完成；移动端使用 Flutter 动画组件，并保留平台导航手势。两端的功能、错误提示、聊天协议和备份格式保持兼容。

验证：Flutter 完整回归 120 项全部通过，桌面 16 组界面及媒体回归脚本全部通过。覆盖快速切页、输入与滚动位置保留、弹窗焦点恢复、Android 预测返回和 iOS 边缘返回、运行时减少动态效果、新消息与历史区分、发送确认不重播、缩略图复用、视频节点与 GlobalKey 生命周期。新增动效模块及相关测试的定向静态分析通过。

全量测试曾发现选图测试在真实时间环境内点击，导致短提示在高负载下先于断言过期；仅将测试点击移回 widget 测试时钟，保留原提示期限和业务断言，定向 11 项及随后完整 120 项回归通过。应用源码没有为测试修改提示行为。

macOS 完整应用严格签名、状态自检、两个采集辅助程序来源及 ZIP 执行权限验证通过。Android 完整 APK 版本和签名证书、SQLite 插件注册、Shorebird 引擎及 auto_update=false 验证通过。构建输入与发布工作区逐字节一致。真实 Android 机型及 macOS WKWebView 的帧时间尚未测量，不宣称所有设备均达到固定帧率。
