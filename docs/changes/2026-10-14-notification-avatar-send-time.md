# 移动端通知头像与单条发送时间

此前 Android 聊天子通知改为逐条 BigTextStyle 后没有传入发送人头像，展开系统通知时只能看到文字。本次恢复默认或自定义头像，使用系统装饰的自定义通知内容布局：单条折叠、展开、悬浮视图均包含头像、昵称、消息正文及右下角时间，原生大图标提供系统简化布局的头像信息。头像使用既有账号与头像版本缓存，图片获取失败回退默认头像；读取头像后再次检查当前聊天和本机已读序列，避免网络返回后补弹已读消息。隐藏消息预览时不获取或显示发送人的头像、昵称和正文。

时间来自服务器每条消息的 createdAt，按手机本地时区显示当天 HH:mm、跨天 MM/dd HH:mm、跨年 yyyy/MM/dd HH:mm。发送时间与通知接收时间分开传递，旧接口未提供发送时间时显示“时间未知”，不把同步或收到通知的时间伪装为发送时间。应用内顶部卡片的时间置于“回复”下方右侧，长日期分两行，大字号时完整缩放展示。

单条系统通知采用 Notification.DecoratedCustomViewStyle、48 dp 折叠内容以及独立展开内容，保留系统应用名称、展开按钮和通知渠道。每条消息仍使用独立标识，沿用五条/好友、二十条/账号上限、批量只提醒最新一条、点击打开对应聊天和通知清除策略。锁屏隐藏内容版本保留时间，使用匿名内容和应用图标。

整组通知收起时，Android 7.0 及以上的 SystemUI 会重新排版子通知摘要，厂商实现还可能限制行数。因此无法保证小米/HyperOS 的每条摘要时间固定在右下角。为保证可见摘要也带时间，标准子通知正文以时间开头，分组摘要各行同样包含各自的发送时间；单条自定义内容中的时间位于右下角。应用不能控制系统最终是否省略某条消息或替换布局。

继续遵循用户的移动端范围要求，桌面源码、界面和版本保持不变，本次仅发布 Android 0.2.23 / 2026101404 完整 APK，不发布 macOS 或热更新。无服务端部署或数据库变更。

参考：[Android 自定义通知内容](https://developer.android.com/develop/ui/views/notifications/custom-notification)、[Android 分组通知规则](https://developer.android.com/develop/ui/views/notifications/group)。

## 验证

Android 原生 Robolectric 测试十八项通过：实际应用 RemoteViews 并检查三种布局中的头像、时间文字、右侧/底部位置与消息内容，检查系统摘要每行时间、锁屏匿名版本、内容隐藏、跨日跨年本地时间和旧版清除/分组策略。Flutter 测试八项通过，包含右下角时间、窄屏大字号、长日期完整显示、真实中文字体视觉预览，以及既有消息卡片交互和账号/生命周期清理；静态分析无问题。

暂无在线 Android 调试手机。自动化确认字段与布局提交正确，实际 HyperOS 对分组摘要或自定义通知的最终渲染仍需手机验证。
