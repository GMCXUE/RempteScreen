# 聊天图片、复制和撤回

桌面主客户端 `apps/desktop-rs/` 与 Flutter 移动客户端同步实现，不修改旧 Electron 和早期 Android 原型。

## 使用方式

- 聊天输入框旁增加图片按钮，选择后先预览，再确认发送；取消不会发送。失败保留预览，重试沿用同一个消息编号，避免重复消息。
- 图片以缩略图显示，点击查看完整图片。移动端支持双指缩放；图片加载前预留位置，避免聊天列表跳动。
- 桌面端右键、消息旁的操作按钮或 Shift+F10 打开菜单，可复制正文或选中的正文。移动端长按消息复制，或打开“选择文字”进行局部选择。复制不会携带时间和头像信息，成功与失败均有提示。
- 本人发送的文字和图片在服务端记录的发送时间起 2 分钟内可撤回；通话记录不支持撤回。双方显示“你撤回了一条消息”或“对方撤回了一条消息”，不再显示原文或缩略图。
- 撤回会关闭已打开的大图、桌面消息菜单和移动端文字选择窗口；未读计数排除已撤回消息。撤回同步沿用聊天轮询，桌面通常不超过 4 秒，移动端通常不超过 3 秒，网络异常时待同步恢复。

## 服务端与协议

新增会话鉴权接口：

| 接口 | 请求字段 | 返回 |
| --- | --- | --- |
| `POST /v1/social/send-image` | `peerId, clientId, image` | `message` |
| `POST /v1/social/message-image` | `peerId, messageId` | 完整 JPEG 的 `image` data URI |
| `POST /v1/social/recall` | `peerId, messageId` | 撤回后的 `message` |

图片输入只接受静态 JPG、PNG、WebP，最大 8 MiB、解码像素最大 2400 万。服务端去除元数据、校正方向，按最长边 2048 像素压缩为 JPEG，透明区域转换为白色；缩略图最长边 320 像素。原上传文件不保存，不提供原图无损下载。图片请求体上限 12 MiB，其他接口保持原有上限；超限返回可读的 JSON 413 响应。

图片内容保存在 PostgreSQL `chat_images`，缩略图及尺寸保存在消息元数据。读取、发送和撤回在同一好友对事务锁下进行鉴权，不公开静态图片地址。撤回删除保存的图片、原文及缩略图元数据；已经复制到系统剪贴板或由对方另存的内容无法清除。

`messages` 增加 `syncCursor`、`loadedFrom` 输入与 `updates`、`syncCursor`、`serverNow` 输出。撤回使用独立递增的 `edit_seq`，最多每页 50 条，避免仅按新增消息序号拉取导致漏掉旧消息的撤回。重复撤回和相同 `clientId` 的发送重试幂等，客户端忽略迟到的未撤回快照，防止原内容重新出现。服务端仍是时间限制和发送者权限的最终判定方。

数据库迁移为新增表、列和索引，可重复运行，保留已有账号、好友和历史消息。旧客户端不主动同步撤回更新，需服务端与双端一同升级才能完整使用。
