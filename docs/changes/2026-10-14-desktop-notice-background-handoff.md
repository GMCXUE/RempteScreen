# 桌面消息卡片与 Android 前后台通知交接

用户明确要求优化桌面红框中的消息提示；本次仅替换桌面前台聊天消息的黑色文字条，不更改移动端已确认的顶部横幅样式。普通复制、文件操作及错误提示仍共用原有提示条。

桌面前台消息在右上方显示浅色卡片，包含发送人头像、实际发送时间、最多两行摘要、查看消息和关闭按钮。卡片不会抢焦点；鼠标停留或键盘焦点位于卡片时暂停自动关闭。支持减少动态效果。账号切换、失焦、进入对应会话及修改通知设置会清理卡片；隐藏预览不暴露姓名、正文或头像，禁用通知、免打扰、拉黑及账号不匹配不会展示。

Android 存在可确认的交接漏洞：原生服务将前台消息入队后即推进通知游标，Dart 在切后台时可能尚未画出横幅，结果既没有横幅，也不会补发系统通知。改为保存待确认序列，横幅完成进入动画且仍在前台时才确认通知已展示。未确认消息保留到下一次后台同步，由原生服务提交系统通知；系统提交失败继续重试。旧横幅确认不能消耗新的待确认消息；其他设备已读也不吞掉本机待展示的消息。前台已展示内容不在后台重复通知。退出或切换账号仍沿用现有隔离。

Android 服务状态检查同时核对同步线程是否存活，启动时可恢复已停止的线程。双端系统通知诊断增加最近成功同步时间，帮助区分同步停滞和系统通知设置问题。

这修复了一个明确的软件时序问题，并不等于已确定用户手机本次完全收不到后台通知的唯一原因。本机没有连接 Android 测试设备，用户已确认是切其他应用或锁屏后无通知，重新打开可看到消息；仍缺少故障时的设备服务与系统通知状态。进程被强行停止、冻结或断网的接收范围不变；未增加厂商推送、FCM 或 APNs，也未主动调整系统后台限制。
