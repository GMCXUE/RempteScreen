# 消息同步提示不再常驻

桌面消息页在同步失败时把错误写到聊天顶部的红色栏，成功同步时没有清除，因此连接恢复后仍显示“连不上服务器，请检查网络或服务器地址”。此前通话提示已从该栏移走，但消息同步仍在使用它。

本次移除桌面及移动端聊天顶部的错误条。自动同步失败使用约 2.2 秒的轻提示；同一故障持续轮询时只提示一次，多个同步请求遇到相同错误合并提示。联系人、消息和已读同步各自恢复，恢复旧故障不会隐藏较新的操作反馈。已有消息和未发送草稿保留；首次未加载出数据时提供居中的“消息暂时无法同步 / 重试”入口，成功后移除。

发送失败仍显示在输入区域，保留草稿以便重试。已读请求失败后，后续轮询使用已有消息的最后序号重试，即使没有新增消息也可恢复已读状态。

实际服务器 `/v1/health` 检查成功，未修改服务端。移动端构建检查同时发现原生桥接声明缺失，补齐与已实现的通话服务、悬浮入口及通知点击事件对应的声明，保留此前后台通话能力。
