# 接收文件所在目录入口

桌面端和移动端的成功接收记录提供“打开所在目录”。只有接收完成、保存成功且具有保存位置的记录展示入口；发送记录和失败记录不展示。

macOS 使用 Finder 定位并选中文件。文件已删除或移动时显示错误。桌面命令只允许定位下载目录下 `RemoteScreen-Files` 内的现存文件。

安卓端在传输记录及最近接收卡片提供文件夹按钮，优先调用系统文件管理器打开 `Download/RemoteScreen-Files`。由于文件管理器对目录 Intent 的支持不同，无法处理目录打开请求时退回系统下载列表；无法启动时显示“无法打开文件所在目录”。

该入口的真机点击效果尚未验证。
