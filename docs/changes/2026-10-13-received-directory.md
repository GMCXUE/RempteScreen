# 接收文件目录打开兼容修复

Android 接收文件通过 MediaStore 写入 `Download/RemoteScreen-Files`，但打开目录时构造的是系统 DocumentsProvider URI。之前给此 URI 添加读授权标志；应用并不持有该目录的可转授权限，可能被系统拒绝。旧逻辑只在 ActivityNotFoundException 时尝试系统下载页面，SecurityException 会直接报错。

现在目录跳转不附加未经持有的 URI 授权，任何运行时启动失败都继续尝试系统下载页面；两种方式都失败才显示手动查找提示。无需新增存储权限，不更改保存位置、文件内容或接收协议。未取得问题手机日志，因此具体厂商拒绝原因仍需真机确认。

桌面和移动端已完成接收记录都展示实际保存位置（包含重名保存后的文件名），打开失败时均提供手动查找路径。移动端路径可选择复制。平台差异：macOS 继续在 Finder 定位文件；Android 不保证所有厂商文件管理器都支持定位目录，允许降级到系统下载页面，未用目录授权选择器冒充文件浏览器。

验证：Android 四项原生回归覆盖权限拒绝、目录处理器缺失、首选成功和全部失败；Flutter 竖屏用例验证实际保存路径及无法打开时的对话框；桌面浏览器用例验证实际路径和打开失败提示；Flutter 静态检查。尚未在用户手机上复测。

整包版本：macOS 0.2.11、Android 0.2.17，buildCode 2026101306。仅整包，不发布热更新。
