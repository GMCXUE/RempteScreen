# 移动端样式优化

按用户本次指定移动端的范围优化 Flutter 主题和首页、投屏、我的设备、我的页面；移动端使用适配手机的底部导航和留白，桌面保持既有布局。未增加客户端功能或修改协议。

统一浅色背景、蓝色强调色、圆角卡片和触控按钮，首页增加轻渐变欢迎区域及文件传输图标，设备代码和密码独立分组；设备列表使用图标底框，会话操作改为可换行布局，连接表单标题适配窄屏。保持原有四个底部导航入口与通话/投屏逻辑。

仅修改源码，不覆盖安装。静态检查仅剩原有 AudioSessionOptions 警告；需要后续真机确认不同屏幕和字体尺寸下的观感。

## 草图确认后的设备页和导航

用户确认 mobile-navigation-sketch-v2.png 后，设备页改为当前设备和其他设备独立卡片，移除重复标题和刷新按钮，显示在线数量和状态。主页面标题栏缩至 64，底部使用高度 56、左右边距 16 的圆角导航条，无大块选中背景，保留系统安全区及四个入口的语义选中状态。此轮按用户请求构建并覆盖安装 Android；桌面没有此次移动布局改动。静态检查仅剩已有实验性音频 API 警告。
