# 紧凑视频窗与投送结束处理

桌面和 Android 原生视频悬浮窗统一为 180×135，取消底部标题栏和关闭按钮；支持拖动、收起为 56×56 圆形视频头像，再点击展开。桌面悬停显示拖动提示和收起按钮，Android 点击视频收起；桌面使用 Tauri macOS 透明窗口能力，测试签名分发保留。

双端观看会话监听目标 caster 的离线、屏幕轨道撤销及房间连接结束，清理画面和音视频，关闭观看窗口/页面并提示“设备名称 已停止投送”。其他观看者离开或摄像头轨道撤销不结束投屏。旧版 UNKNOWN 且名称为 screen 的屏幕轨道继续兼容。

观看方网络重连保留 30 秒恢复时间。投送端强杀/关机由 LiveKit 服务端判定离线后通知，检测时间受心跳超时和网络影响，不能保证瞬间发现；不使用画面无变化作为断开依据。桌面按会话停止标记核对当前会话，迟到的旧事件不会结束新会话。

本次不部署、不覆盖安装；仅静态和本地编译检查，尚未进行设备间通话及关机实测。

验证：桌面 cargo check --offline 通过；Android arm64 release APK 编译通过；Flutter analyze 仅报告已有 AudioSessionOptions 实验性 API 警告；桌面修改的 JavaScript 语法检查通过。没有部署、安装或双设备实测。
