# 聊天发送与滚动

桌面和安卓在发送图片或文字后立即清空输入栏，在聊天中显示发送中的消息，上传期间可以继续输入、发送或切换会话。失败消息显示“发送失败 · 重试”，重试沿用原消息编号，不重复发送同批已完成的图片或文字。发送队列绑定登录会话并在应用内存中保存；退出账号清除队列。服务器返回 clientId，轮询可对账回执丢失的消息。

移动端进入会话时持续跟随布局变化定位到最新消息，键盘和功能栏压缩列表可用高度，最新消息位于输入栏上方。主动翻看旧记录时保留位置，历史搜索定位不受影响。桌面进入会话、窗口高度和输入框高度变化时也维持底部位置。

本次完整更新包含紧凑输入栏、输入文字时隐藏移动端加号、桌面独立图片窗口及移动端图片浏览工具。保留热更新基础设施，不发布新的热更新补丁。

验证：移动端混合长消息首次定位、键盘挤压和历史阅读位置；延迟上传、个别失败和稳定编号重试；轮询先收到消息再丢失回执；退出账号忽略迟到回执；既有聊天图片复制、撤回、分页和搜索定位回归。
