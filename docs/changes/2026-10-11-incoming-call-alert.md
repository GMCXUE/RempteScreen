# 未接来电通知与图标按钮

- macOS 原生来电卡片仅显示等待接听的来电。接通、其他设备接听、拒接、对方取消及超时后关闭；接通中的临时状态不再阻止关闭。
- 卡片由 340×142 缩为 320×108，右下角使用两个 32 点圆形按钮，绿色电话表示接通，红色电话表示挂断。保留鼠标提示及辅助功能名称。
- 桌面端在接通成功后立即关闭卡片，并记录已处理的通话；后台获取头像期间收到的旧来电数据不能再次显示通知。
- 移动端应用内来电卡片同步改为右下角绿色接通、红色挂断图标。按钮使用至少 40 点大小以适应触摸。接通后关闭顶部来电卡片，收起通话时保留原有底部返回通话入口。
- 安卓在通话状态变为已接通、对方取消或网络超时后主动清理来电通知。通知提交和取消使用同一把锁，避免头像加载结束后重新弹出已处理的来电。
- 平台差异：macOS 使用独立原生来电卡片；安卓系统通知保留系统 CallStyle，按钮外观由系统决定。Windows 系统通知沿用系统外观，本次 macOS 卡片样式不应用到 Windows 系统通知。

验证：桌面 Rust 策略 5 项、安卓原生策略 6 项、Flutter 通话状态与界面 7 项检查通过。macOS 原生卡片检查覆盖真实按钮路由、接通等待状态清理、已接通/已结束/呼出隐藏和超时关闭；渲染预览确认图标存在且位置正确。`cargo check --locked --offline`、Objective-C 编译检查及相关 Dart 静态分析通过。未进行真实账号端到端呼叫，也未部署或覆盖安装。
