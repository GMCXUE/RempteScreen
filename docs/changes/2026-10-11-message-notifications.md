# 消息红点与系统通知

双端补齐消息导航总未读、消息分栏未读、好友分栏申请数、最近会话/好友列表的单好友未读。好友管理菜单不再覆盖未读提示；移动端约 2 秒刷新状态。已读仍以账号服务端游标为准，只有前台正在查看的聊天才标记已读。

## 通知与点击

服务端 state 为每位好友增加 lastIncomingSeq、lastIncomingText、lastIncomingKind，仅表示对方发来的最新消息，不把自己发送的内容当作新消息。好友申请带版本时间。通知按最新收到消息游标去重，未读数量恰好不变时也不会漏掉新消息；已查看聊天不再额外弹出消息通知。首次接入或首次出现的会话若有未读，显示一条汇总提醒；已通知游标保存到本机，重启不会反复通知同一批消息。

桌面使用 Tauri 官方通知插件，原生线程独立同步消息与来电，不依赖 WebView 是否正在显示消息页。通知包含联系人和消息内容；语音/视频来电区分文案，提供接听/拒绝动作。点击通知唤起主窗口并进入聊天或处理对应来电。应用 Dock 角标包含未读、好友申请和待接来电。点击旧账号或已结束来电的通知会被拦截。macOS 插件无法主动撤销已经投递的通知，因此通知中心可能保留历史条目，点击时必须再次核对服务端通话状态；仅应用仍运行时接收通知。

安卓 MessagingService 使用 remoteMessaging 前台服务及低优先级常驻通知，原生账号轮询不依赖 Dart 页面或后台定时器。文字消息使用高优先级聊天通知，点击打开会话；好友申请可打开申请页；语音/视频使用 CallStyle 来电通知（低版本退化为操作按钮），提供接听/拒绝、来电铃声和振动。未接来电按剩余响铃时间自动撤下，接听或挂断立即取消来电通知。进入正在查看的聊天、已读、删除好友或处理申请后撤销对应安卓通知。

原生来电查询采用独立通知客户端标识，不获取选中通话的媒体权限，也不会替真正的通话端续租，避免 Flutter 媒体失联但通知服务让通话永久保持。接听通过唤起应用后由原账号通话控制器进行。退出登录停止安卓消息服务并清理通知。账户切换清理旧通知，通知携带账号身份避免旧点击串号。通知权限由系统管理；安卓启动时请求授权，服务启动失败不阻止应用前台使用。

## 平台范围与限制

当前覆盖 primary Rust 桌面（Mac）与 Flutter Android；没有配置厂商推送/FCM/APNs。安卓后台接收依赖消息前台服务获准运行，系统强制停止、关闭通知权限、厂商省电或设备断网可阻止提醒，无法等同于微信的系统推送；启动应用后恢复同步。Flutter iOS 需要 APNs 和通话系统集成，不在当前已安装的安卓范围内。没有后台采集摄像头/麦克风的新授权路径。

参考：[Android 消息前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types#remote-messaging)、[Android CallStyle](https://developer.android.com/develop/ui/views/notifications/call-style)、[Tauri 通知插件](https://v2.tauri.app/plugin/notification/)。
