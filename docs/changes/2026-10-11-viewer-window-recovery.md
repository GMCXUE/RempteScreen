# 桌面观看窗口恢复

用户报告电脑观看安卓画面的窗口卡住或打不开。线程采样时主线程仍在正常运行循环，未确认主线程死锁；修复代码中发现的窗口恢复与画面等待缺陷。

已有观看窗口重新打开时，原代码只聚焦且忽略失败。现在依次显示、恢复最小化、聚焦，并记录操作错误。前端请求打开窗口改为异步阻塞任务，超过 12 秒向用户报告超时，避免按钮一直无响应；再次打开按钮在操作期间禁用，失败有可见提示。

拉帧请求原先没有超时，未触发图片回调就一直保持 pending。现在单帧等待 3 秒后重试；断开时取消加载并作废旧回调，重连可以启动新的画面循环。用模拟图片与时钟执行实际前端代码，验证卡帧重试、断开取消和重连通过。

这是桌面端原生窗口与 JPEG 协议显示路径的修复；安卓使用 Flutter 路由与 WebRTC 渲染器，不经过这些窗口或拉帧代码，因此没有同类修改。实际原生窗口恢复与安卓实机投屏效果仍需确认。
