# 大图片格式校验堆栈溢出

旧移动端 `chatImageBytes` 使用整段数据 URI 正则校验 Base64。在回归用例中构造8 MB编码图片，修复前稳定抛出 `Stack Overflow`，堆栈为 `_RegExp.hasMatch → chatImageBytes`，因此失败发生在本地草稿处理阶段、上传之前。手机日志未保留此次异常堆栈；上述复现来自同一应用代码的Flutter测试。

移动端改为固定MIME头检查、编码长度/填充检查和单次字符扫描，再解码，不在大字符串上调用回溯正则。解码前检查实际大小上限，继续只接受JPG/PNG/WebP、8 MB以内的图片。桌面端同步使用相同检查规则，保持现有图库与粘贴交互。服务端协议及压缩逻辑未改动。
