# 账号卡通头像

桌面端账号菜单、消息页的“我的账号”和移动端“我的”提供“更换头像”。内置小橘猫、小柴犬、小狐狸、小白兔、小棕熊、小熊猫、小企鹅、小猫头鹰，预览后点击“保存头像”提交；失败时保留选择并显示错误，不修改账号头像。

头像随账号保存在 PostgreSQL `users.avatar_id`。启动迁移为已有账号补上默认小橘猫，新账号使用相同默认值。`POST /v1/social/avatar` 只接收内置的 `avatarId`，仅更新当前登录账号，忽略外部传入的账号 ID；需要有效登录凭据。账号公开资料、好友/申请/搜索/黑名单返回 `avatarId`，通话返回 `peerAvatarId`。旧服务响应缺失字段或未知头像 ID 时双端均显示小橘猫。

两端好友与会话头像、聊天标题、通话占位头像使用相同资源；macOS 原生来电小窗和 Android 消息/来电系统通知同步使用头像。客户端内置图片，无额外图片下载或摄像头/相册权限。此阶段仅提供默认头像选择，不含图片上传。

资源原稿及目录为 `assets/default-avatars/`，`tools/generate-default-avatars.mjs` 生成矢量原稿，PNG 以 256×256 导出。桌面 `ui/avatars/`、Flutter `assets/avatars/`、Android `drawable/avatar_*.png` 使用相同 PNG。资源 ID 是持久化协议，不能随意重命名。
