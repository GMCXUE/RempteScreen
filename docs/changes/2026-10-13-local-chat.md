# 本地聊天与迁移

目标：Rust 桌面和 Flutter 移动客户端使用 SQLite 持久化聊天、媒体、撤回和清空边界；按账号隔离。投屏设备目录仍保存在服务端。可靠落盘不等于已读。

同步：账号级顺序消息/编辑增量，事务提交后推进游标，所有会话都同步；媒体下载完整校验后持久化，失败保留重试。旧服务器数据在迁移期间保留，旧客户端兼容。服务器暂存策略为用户选择的 7 天；旧记录必须双方完成可靠落盘确认后才进入清理期限。

跨端备份格式：.rschat，逐行加密记录。首行 JSON {format:RemoteScreenChat,version:1,salt:base64(16 bytes)}；PBKDF2-HMAC-SHA256 210000 次派生 AES-256-GCM，nonce 为 4 字节零加 8 字节大端记录序号，AAD 为原始首行 UTF-8 + ':' + 序号十进制。后续每行是 ciphertext+16byte tag 的 base64。媒体按 256KiB 分块。必须收到经过认证的结束记录且无尾随数据；账号匹配、完整性校验、事务合并去重、撤回优先、清空边界不能回退。密码至少 8 个字符；不导出账号令牌或设备连接凭据。

备份和导入均采用文件；可通过现有设备文件传输或系统文件复制迁移。导入失败回滚，不覆盖现有记录。原始数据库不直接跨端复制。

验证计划：重启/断网/账号隔离；分页恢复/撤回/清空；磁盘失败不确认；双向跨端备份/错密码/截断/篡改/重复导入；服务器过期与老客户端保护；macOS 实际运行和 Android 完整包构建。

## 已实现的行为

- SQLite 事务与 WAL/FULL 同步；消息、撤回、清空边界、媒体和已读按账号隔离。只有成功提交的消息和完整校验的媒体才确认可靠落盘，不因此标为已读。
- 全账号消息/编辑增量按提交顺序分配游标，断网显示已保存内容，后台下载会重试，旧记录在双方完成落盘前保护。大整数游标在本地和备份中保持字符串精度。
- 聊天正文和媒体暂存 7 天，仅当双方账号启用本地模式后适用于新消息。迁移前记录在双方保存后再计 7 天；旧客户端兼容。过期后保留少量投递去重和已读/清空所需元信息，不保留聊天正文和媒体。
- 通话或投屏期间暂停后台媒体下载，文字同步继续；恢复空闲后重试。备份密码派生在移动端独立 isolate、桌面工作线程运行。
- 本地备份和恢复入口：桌面“设置→聊天记录”，Android“我的→聊天记录→本地保存与迁移”。备份只包含本机已经保存的记录和媒体，页面显示待下载数量。下载未完成的文件仍需在暂存期内补齐。
- 迁移：导出密码保护的 .rschat 文件，经现有设备文件传输、USB 或系统文件复制送到目标设备，登录同一账号导入。事务恢复、媒体哈希校验、重复合并去重；撤回和清空边界不回退。账号和设备凭据不导出。移动文件导入/导出沿用 Android 的系统文件选择和公共下载目录桥；iOS 尚未发布该文件桥。
- 设备目录、好友关系和账号仍由服务器管理。未发送草稿不属于聊天备份。

## 验证

Mac 上完成全部 Flutter 回归：95 项通过；Rust 默认回归 34 项通过，7 项真实媒体集成测试保持忽略。新本地存储用真实 SQLite 验证重启、断网、账号隔离、只读/写入失败不确认、损坏媒体重试、重复导入、错密码和截断回滚、撤回优先与清空边界；macOS 与 Android 实现的 .rschat 文件实际双向互导，包含中文和跨多个分块的媒体。桌面备份界面隔离浏览器检查通过。服务端 PostgreSQL 独立数据库检查涵盖旧记录保护、7 天过期、提交顺序、越权、落盘/已读隔离以及过期后的已读和清空；既有聊天历史、图片、视频和通话回归通过。

生产部署前已在服务器本地建立 0600 权限的数据库及代码快照，未下载用户聊天数据到开发机器。完整安装包发布记录另行追加。
