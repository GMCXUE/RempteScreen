# 持续显示的来电操作

macOS 系统横幅的停留时间和按钮颜色由系统管理。本次使用 AppKit 的独立通话浮层提供持续提醒，不重复发送普通来电横幅；消息通知保持原有方式。

- 来电浮层位于屏幕右上角，可以拖动，无关闭按钮。绿色“接通”、红色“挂断”操作复用现有好友通话流程。
- 本机接通后保留浮层，显示通话时长、已接通状态以及红色挂断按钮。接通按钮此时禁用。
- 对方取消、挂断、本机结束、其他设备接听、账号切换时清理浮层。服务端轮询间隔 4 秒；本机挂断立即隐藏。来电保留至原有 45 秒超时，活动通话网络状态超过 30 秒未更新也会清理。
- 通话归属由网页端的实际通话结果确认，通知轮询仍使用独立 clientId，不代替媒体端发送通话心跳。按钮事件检查 callId、账号和状态，旧来电操作不影响新通话。
- Android 应用内同步使用绿色接通、红色挂断；收起通话后的返回入口增加直接挂断按钮。应用内浮层在通话结束时消失。Android 系统 CallStyle 通知的按钮布局、颜色、文字由系统管理，无法复刻 macOS 自定义浮层；旧系统可自定义动作文字，已统一。

验证：Rust 浮层显示策略覆盖来电、本机接通、其他设备接通、已结束及本机已挂断；桌面界面检查原生动作路由和过期事件；Flutter 通话界面检查收起后挂断入口及结束后清理。macOS 原生桥接通过编译。没有覆盖安装或发起真实好友通话。
