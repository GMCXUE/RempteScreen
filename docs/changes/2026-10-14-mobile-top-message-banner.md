# 移动端应用内顶部消息卡片

移动端处于前台且当前没有查看发送人的聊天时，用顶部白色圆角卡片代替底部消息 SnackBar。左侧圆形头像带消息标识，中间显示好友备注或昵称及“私信了你：消息摘要”，右侧提供“回复”；点击卡片或按钮进入对应聊天，上滑收起，五秒后自动消失。采用应用蓝色按钮、顶部安全区与滑入淡入效果，系统减少动态设置生效；使用屏幕阅读器时不自动收起。长昵称省略，消息摘要最多两行，支持大字号。

卡片位于应用 Navigator 之上，可覆盖其他页面；来电卡片和强制更新层仍有更高优先级。连续消息使用最新摘要并重置计时，旧提示的计时、回复和退出动画不能影响新卡片。按登录账号隔离，退出账号及切后台时清理；当前正在查看的好友不重复弹出，超过八秒的队列提示不补弹。打开聊天的异步查询再次检查账号与页面存活，避免重复打开。

Android 原生桥提供结构化昵称、消息、头像版本、内容预览开关和收到时间。隐藏预览时原生层移除昵称、消息和头像字段的敏感内容，Flutter 层再次遵守当前预览设置，卡片仅显示 RemoteScreen 和“收到新消息”；设置保存时收起已有卡片。通知不添加服务器记录或新的文件保存。

本次按用户明确要求仅修改移动端，桌面端保持原有提示、源码与版本。这是项目跨端一致规则的用户指定例外。Android 发布 0.2.22，构建 2026101403，完整 APK 安装包；不发布 macOS 或热更新。后台系统通知、通知栏分组与来电逻辑沿用已有行为，无需部署服务器或迁移数据。
